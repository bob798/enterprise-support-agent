# Knowledge Base

三类内容，面向不同使用场景。

| 目录 | 内容 | 使用时机 |
|---|---|---|
| `practitioner/` | 交付者手册：架构决策思维框架、设计原则、自查问题 | 做设计、复盘项目、准备技术面试 |
| `communication/` | 沟通工具包：AI 价值三层模型、数据依据、FDE-企业主断层 | 售前沟通、项目立项、高层汇报 |
| `research/` | 背景调研：行业现状、知识表示方法综述 | 立项前了解行业背景，写文章找数据来源 |

---

**两篇主文档的关系：**

- `practitioner/ai-delivery-principles.md` 帮你**想清楚**——从约束推导设计，而不是背答案
- `communication/enterprise-communication.md` 帮你**说清楚**——用企业主关心的语言谈 AI 价值

两者服务不同时机，互不替代。
